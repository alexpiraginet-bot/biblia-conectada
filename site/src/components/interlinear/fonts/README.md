# Interlinear script fonts

These unchanged WOFF2 subsets and SIL Open Font License files are copied from the existing repository blobs under `estudos/biblia-marca/motion/public/fonts/`. No study source was edited. Byte counts, source paths and SHA-256 values are in `provenance.json`.

- Noto Serif Hebrew, Hebrew subset, weight 500; copyright 2022 The Noto Project Authors.
- Gentium Book Plus, Greek and extended Greek subsets, weight 400; copyright 2003–2022 SIL International.

`interlinear.module.css` declares route-local faces with Unicode ranges. These fonts are requested only by the interlinear views, not by the global reading shell. The original font files and internal names are unchanged; the CSS family aliases isolate these faces from other site typography.
